# Ironvale

A WoW-Classic-style co-op RPG for 1–5 players.

**[Download the latest release →](https://github.com/filipm89/ironvale-r/releases/latest)**

## Requirements

- Windows 10 or later
- An internet connection (required to play)

## Installing

1. Download `ironvale.exe` from the latest release
2. Put it anywhere you like — Desktop, Downloads, etc.
3. Double-click to play. No installation needed.

The game updates itself automatically on launch when a new version is available.
